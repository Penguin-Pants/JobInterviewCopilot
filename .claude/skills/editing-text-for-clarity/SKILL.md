# Clarity edit without changing meaning

Follow AGENTS.md authorization modes and decision checkpoints. Use for meaning-preserving edits only, not substantive rewriting, requirements discovery or fact expansion.

Edit the supplied text for clarity and concision only.

Preserve:

- every original idea and intended meaning
- the existing structure unless a small change is required for readability
- names, dates, numbers, citations and technical terminology exactly
- uncertainty or qualification in the source

Remove repetition, confusing wording and unnecessary length only when meaning is preserved. Do not add new information or fill gaps with likely answers.

If a material ambiguity prevents a safe edit, leave that passage unchanged and ask one focused question instead of choosing an interpretation.

Return the revised text. List unresolved ambiguities only when any remain.
